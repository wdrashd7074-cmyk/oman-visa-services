نموذج طلب خدمة

أدخل بيانات التواصل الأساسية فقط. لا ترفع جواز السفر أو وثائق حساسة عبر هذا النموذج.

تُحفظ البيانات في قاعدة بيانات الموقع بعد نشره وربطه بخادم صالح. لا ترسل أرقام بطاقات أو كلمات مرور. راجع سياسة الخصوصية قبل الموافقة.

تواصل معنا

يمكن إضافة رقم واتساب الكامل بعد تأكيد رقم خدمة العملاء.

الخصوصية باختصار

يجب نشر سياسة خصوصية كاملة قبل استقبال العملاء، توضح البيانات المجمعة، والغرض منها، ومدة الاحتفاظ بها، ومن يمكنه الوصول إليها، وطريقة طلب التصحيح أو الحذف. لا تجمع وثائق الهوية قبل إعداد تخزين آمن ومحدد الصلاحيات.
